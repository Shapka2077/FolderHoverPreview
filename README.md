# FolderHoverPreview for C#

Перенос утилиты на WPF / .NET 8 для Windows. Исходники AutoHotkey в соседних
папках не изменяются.

## Возможности

- показывает рядом с курсором содержимое включённых папок рабочего стола;
- позволяет выбирать показываемые форматы в подменю трея; поддерживает
  популярные расширения и пользовательский список;
- включает отдельные пресеты палитр и размеров/эффектов, подсказки и сброс
  оформления к исходным значениям;
- показывает пример оформления в отдельном окне реального размера, используя
  те же элементы, что и превью папки; оно не закрепляется поверх чужих окон,
  а изменения видны до сохранения;
- позволяет скрыть заголовок папки и тонко настраивать расширенный диапазон
  размеров, скруглений и отступов;
- позволяет растягивать окно настроек за край;
- добавляет в контекстное меню папки рабочего стола пункт
  **«Превью при наведении»** с галочкой текущего состояния;
- использует UI Automation для получения позиций значков рабочего стола;
- размещает окно рядом со значком и выбирает сторону с наименьшим перекрытием;
- показывает собственный значок «папка с глазом» в области уведомлений;
- подсвечивает плитку мягким фоном и окрашивает её подпись в золотистый при наведении;
- позволяет из меню трея включать и выключать пункт Проводника (по умолчанию он
  включён), а также управлять автозапуском.

Список включённых папок хранится в `%LOCALAPPDATA%\FolderHoverPreview\enabled-folders.txt`,
а настройки форматов — в `%LOCALAPPDATA%\FolderHoverPreview\preview-formats.json`.
Настройки оформления хранятся в `%LOCALAPPDATA%\FolderHoverPreview\preview-theme.json`.
В новой установке список папок пуст: включите нужные папки через пункт
«Превью при наведении» в контекстном меню папки рабочего стола. Уже сохранённые
пользовательские списки папок при обновлении не очищаются.

По умолчанию отображаются ярлыки Windows (`.lnk`), интернет-ссылки (`.url`) и
программы (`.exe`). Остальные популярные типы и собственные расширения можно
включить в подменю «Форматы превью» в трее.
Оформление открывается из меню значка в трее через **«Скины и оформление…»**.
Цветовые скины и пресеты размеров/эффектов независимы друг от друга. Выбранная
палитра применяется к окну настроек и ко всем меню/подменю трея. Палитры и тень
реализованы встроенными средствами и входят в `.exe`; внешние эффекты и загрузка
дополнительных файлов не требуются.
В редакторе есть контрастные палитры, включая «Неон и графит», «Лагуна и коралл»
и «Аметист и лайм», отдельные пресеты размеров, а также сброс всего оформления.

## Сборка и запуск

Для сборки нужен **.NET 8 SDK** и Windows:

```powershell
dotnet publish .\FolderHoverPreview.csproj -c Release -o .\dist
```

**Версия 4.0 — автономная сборка для Windows x64.** Публикация создаёт один
сжатый `dist\FolderHoverPreview.exe` со встроенным .NET 8; на компьютере
пользователя не нужно отдельно устанавливать .NET или AutoHotkey. Передавайте
только этот `.exe`. При старте программа регистрирует контекстный пункт в
`HKCU\Software\Classes` и работает в фоне.
Второй запуск не создаёт ещё один экземпляр. Чтобы выключить программу,
нажмите правой кнопкой по её значку в области уведомлений и выберите «Выход».
В этом же меню можно удалить пункт из контекстного меню папок или переключить
автозапуск текущего пользователя.

## Примечания

- Автозапуск по умолчанию выключен.
- Перенос на C# не является гарантией совместимости с каким-либо античитом.
