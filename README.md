# FolderHoverPreview

Наведите курсор на папку рабочего стола, чтобы посмотреть её содержимое и
открыть нужный файл, не открывая саму папку.

## Как пользоваться

Скачайте архив из раздела Releases, распакуйте его в постоянную папку и
запустите `FolderHoverPreview.exe`. Программа появится в системном трее.
Сборка рассчитана на Windows x64 и не требует отдельной установки .NET.

При первом запуске список папок пуст. Чтобы включить превью для папки рабочего
стола, нажмите на неё правой кнопкой мыши и выберите «Превью при наведении».
В Windows 11 этот пункт может находиться в разделе «Показать дополнительные
параметры». Повторное нажатие отключает превью для папки.

В меню значка в трее можно:

- выбрать форматы файлов, которые показываются в превью, или добавить свои;
- настроить цвета, размеры, отступы и другие параметры оформления;
- включить автозагрузку или убрать пункт из контекстного меню папок;
- открыть файл со списком включённых папок.

По умолчанию в превью отображаются ярлыки Windows (`.lnk`), интернет-ссылки
(`.url`) и программы (`.exe`). Автозагрузка по умолчанию выключена.

## Настройки

Настройки хранятся в `%LOCALAPPDATA%\FolderHoverPreview`:

- `enabled-folders.txt` — список папок с включённым превью;
- `preview-formats.json` — форматы файлов;
- `preview-theme.json` — оформление.

Настройки остаются на месте при обновлении или удалении программы. Перед
перемещением или удалением `.exe` выключите автозагрузку и пункт меню папок
в трее, затем выберите «Выход».

## SmartScreen

Файл не подписан сертификатом издателя. Поэтому браузер или Windows могут
показать предупреждение при скачивании или запуске. Для проверки целостности
рядом с архивом опубликована его контрольная сумма SHA-256.

## Сборка

Для сборки нужны Windows и .NET 8 SDK:

```powershell
dotnet publish .\FolderHoverPreview.csproj -c Release -o .\dist
```

Результат — автономный `dist\FolderHoverPreview.exe` для Windows x64.
